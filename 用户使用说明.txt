自助记 使用说明

欢迎使用自助记。

这是一个本地优先的 AI 记忆卡片与复习 Demo。你可以把想学、想记或想复习的内容复制进去，它会生成知识卡片和题目，并根据你的反馈安排复习。

一、如何打开

如果你拿到的是网页压缩包：
1. 解压压缩包；
2. 确认电脑已安装 Node.js；
3. Windows 用户双击“双击打开-发布版.bat”；
4. 程序会启动一个只服务当前文件夹的本地网页，并自动打开浏览器；
5. 如果浏览器没有自动打开，请访问 http://127.0.0.1:8765/；
6. 关闭启动窗口即可停止本地网页服务。

如果你拿到的是源码项目：
1. 安装 Node.js；
2. Windows 用户可双击“双击启动-源码版.bat”；
3. 首次启动会自动安装依赖；
4. 浏览器会自动打开本地地址。

也可以手动运行：
1. npm install；
2. npm run dev；
3. 打开终端显示的本地地址。

二、是否必须填写 API Key

不必须。

不填写接口信息时，你可以使用临时离线方案体验输入内容、生成卡片、答题、复习反馈等主要流程；真实学习内容建议接入模型生成。

如果你希望 AI 根据真实材料生成更准确的卡片、题目和每日问候，可以在“设置”页填写：
- 模型预设或接口地址；
- 模型名；
- 访问令牌。

三、关于隐私和密钥

- 本地下载版不内置任何密钥；
- 访问令牌只保存在你当前浏览器本地；
- 你可以在“设置”页随时覆盖或删除访问令牌；
- 你的项目、卡片、答题记录主要保存在浏览器本地；
- 如果你使用第三方模型接口，发送给模型的内容会包含生成题目所需的学习材料和必要上下文。

四、基本用法

1. 输入内容
可以输入：
- 一段课程材料；
- 一个学习目标；
- 一句想记住的小事；
- 零散摘抄的小知识。

2. 生成卡片和题目
点击“生成”。
如果目标太宽泛，系统可能会提示你补充基础、用途和目标；你也可以点击“直接开始”。

3. 复习
复习页支持两种模式：
- 直接作答：选择或填写答案后点击“确定”；选择题会按预设答案即时判断；填空题和简答题在有 API 时会由 AI 评分，无 API 时使用本地降级判断。
- 脑中作答：先在脑中想答案，再显示答案并自评。

4. 反馈
每题确认后，你可以反馈：
- 正确；
- 半对；
- 不对；
- 太难；
- 太简单；
- 不相关；
- 复习但不计入掌握度。

系统会根据这些反馈调整后续复习。

五、专注全屏

复习区右上角有“专注全屏”按钮。
打开后会隐藏侧栏和输入区，只保留复习界面。

六、数据导出

首页可以点击“导出数据”，下载当前浏览器中的记忆数据 JSON。

七、清空数据

如果你想重新开始，可以在浏览器设置或开发者工具中清理该网站的本地数据。

八、常见问题

1. 为什么没有真实 AI 生成？
请确认设置页已经填写正确的接口地址、模型名和访问令牌。

2. 为什么本地双击 index.html 不工作？
部分浏览器会限制本地文件加载。建议用静态服务器或部署到个人网站访问。

3. 密钥会被上传吗？
本地版不会把密钥写入项目文件或导出的记忆数据。但如果你填写第三方模型接口，浏览器会用该令牌请求对应模型服务。

4. 我刚才答题的数据会影响别人吗？
不会。你的答题记录保存在你自己的浏览器本地，不会进入发布包。
